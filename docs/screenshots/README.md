# Screenshots

Run the application and capture screenshots of:

1. **Search tab** — Query input, source checkboxes, filters, and results table
2. **Download progress** — Active download with progress bar and stats
3. **Library tab** — Downloaded datasets with disk usage
4. **Analysis tab** — Dataset profiling report

```bash
python run.py
```

Save screenshots as `search.png`, `download.png`, `library.png`, `analysis.png` in this directory.
